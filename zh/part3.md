## GTG-54009:阻斷一個利用 Claude 建立商業監控平台、對伊朗與波斯灣用戶社群媒體帳號建檔的行動

2026 年 6 月,我們封禁一個利用 Claude 打造商業監控平台的帳號,該平台用來分析、分類伊朗與波斯灣地區用戶的社群媒體活動並建檔。調查顯示,執行者是「S2T Unlocking Cyberspace」——公開資料研究指出這是一家以色列-新加坡商業情報供應商——或代其行事的單位。

平台核心功能是監控:標定用戶位置、依編碼過的人口分群、產出語氣如官方文件的阿拉伯文情報簡報。我們的發現與新聞調查網絡 Forbidden Stories 2023 年 2 月的[調查報導](https://forbiddenstories.org/osint-s2t-unlocking-cyberspace-journalists-activists/)互相印證——該報導記錄了一款 S2T 監控產品,是記者在哥倫比亞軍方外洩文件中的一份公司簡介裡發現的;簡介描述的能力與本次觀察到的行為高度吻合。我們在行動仍處試驗階段時就予以攔截,未發現後續(Forbidden Stories 報告所述)階段曾用於真實目標。

### 關鍵發現

* 行為者正建立多品牌系統組合,可能服務波斯灣阿拉伯語客戶。
* 系統擷取海外僑民社群用戶位置,分類為親政府或反政府,並用涵蓋都市、教士、軍方、青年、僑民、鄉村六類的人口分類架構分群。
* 簡報以正式阿拉伯文撰寫、仿政府公文樣式,依波斯灣各國國籍細分情緒分數,並附反敘事建議。
* 另發現超過 255 個合成社群帳號的次要工作線,顯示行為者正囤積假帳號庫存供未來部署。

### 攻擊生命週期與 AI 使用方式

行為者用 Claude 分析內容:一次餵入約 25 則貼文,要求判斷貼文者的人口分類、位置、政治傾向並附信心分數;也要求 Claude 以波斯文、阿拉伯文、英文、德文為(疑似虛假的)人設生成貼文,偽裝成親、反伊朗政權兩方陣營成員,顯示行為者意圖量產假帳號、同時操作衝突雙方。

Forbidden Stories 對外洩 S2T 簡介的調查,描述其服務包括建立假帳號滲透私人 WhatsApp、Telegram 群組、蒐集成員名單、進一步升級為釣魚與裝置入侵。行為者用 Claude 生成的內容,可能是用來包裝可信度、協助假帳號取信目標;後續行動階段我們無法獨立證實。

## GTG-30006:打造境內監控工具

我們發現一名伊朗威脅行為者,利用 16 個單一操作者組織底下的免費 Claude.ai 帳號,開發惡意軟體、遞送管線,以及鎖定境內伊朗人的釣魚入口網站。遞送頁面經設計只對來源 IP 位於伊朗的訪客提供惡意內容,主題環繞規避審查工具與一個捏造的波斯語新聞品牌。

### 攻擊生命週期與 AI 使用方式

#### 釣魚與遞送工具

行為者用 Claude 進行工程開發測試,把專案拆解成表面無害的網頁開發請求。產出包括透過 Telegram 機器人控制的 VBScript 掉落器、假冒 Microsoft Excel 與 Windows 憑證對話框、把憑證傳送到 Telegram 的假 ESET NOD32 防毒登入頁面、ClickFix 風格 Win+R 誘餌、V2Ray 著陸頁,及依地理位置篩選的遞送頁面。Claude 拒絕了十次中九次明顯帶惡意的直接請求,但當使用者拆分工作、在後續較小對話階段分別執行任務時,防護機制表現較不一致。

#### SECOMS64 植入程式

行為者用 Claude 建構 SECOMS64,一套模組化 Windows 植入程式,含鍵盤側錄器、螢幕截圖擷取、可繞過應用程式綁定加密(App-Bound Encryption)的 Chrome 憑證擷取,以及對 Microsoft Defender 與 Intune 的偵察功能。配套元件包括透過 ngrok 通道的 PowerShell 反向 shell、USB 隨身碟傳播機制、瀏覽器資料銷毀模組,及從檔案分享服務取得、經修改以規避防毒偵測的分階段掉落器。

工具組設計取向是針對個人監控:鍵盤側錄器僅在 Telegram 桌面版為使用中視窗時擷取按鍵;螢幕截圖元件以名為「Telegram」的執行檔(搭配相符圖示)運作,經 Telegram 機器人外傳;USB 模組記錄每個接觸過的隨身碟序號,同組工具中的 Android 應用程式會上傳裝置聯絡人、訊息與媒體。持久化採多層設計:登錄檔 Run 機碼、最高權限排程工作、自我刪除批次檔,以及偽裝成字型驅動程式服務、放在固定 ProgramData 路徑的執行檔。另有外傳路徑把資料以含受害者主機名稱的檔名暫存於商用雲端儲存,之後下載並自伺服器端刪除。行為者還測試透過 Telegram 文件處理執行遠端程式碼、評估其他指揮管制框架、把元件包裝成可無主控台視窗執行並繞過 SmartScreen,並將工具包裝成帶仿冒 Adobe 版權聲明的假圖片編輯應用程式。同組工具叢集中還發現清除磁碟的一行指令,以及鎖定特定具名 Windows 使用者的瀏覽器資料銷毀功能。

#### Microsoft 365 信箱竊取

行為者還用 Claude 設計不經 OAuth 同意流程入侵 Microsoft 365 信箱的工具:腳本強制終止 Outlook 處理程序以解鎖憑證檔案,解密受 DPAPI 保護的金鑰,解析 MSAL 權杖快取與 OneAuth 帳號儲存區,並列舉 Windows 認證管理員中的單一登入項目。擷取的權杖被重放到 Outlook 網頁版 API,大量下載信箱內容(含已刪除郵件),部分打包成壓縮檔或經代理伺服器轉送。為規避伺服器端偵測,腳本偽造真正 Outlook 桌面版 User-Agent 字串,並重複使用微軟官方應用程式用戶端 ID,讓流量與原生 Outlook 用戶端難以區分。整場行動中,行為者用 Claude 開發測試這套工具,而非執行實際行動。

### 偵測並反制 Claude 遭用於傳統武器相關活動

自 2025 年 11 月發布[上一份威脅報告](https://www.anthropic.com/news/disrupting-AI-espionage)以來,我們發現新一類違反使用政策與服務條款的濫用型威脅行為者——利用 Claude 開發傳統武器(槍械、飛彈、武裝無人機、炸彈及其他彈藥)相關軟體,以及操控這些武器的鎖定與控制系統。搭配本報告,Anthropic 的前沿紅隊(Frontier Red Team)開發了[新的評測方法](https://www.anthropic.com/research/intelligence-targeting-conventional-weapons-capabilities),衡量 AI 在戰術情報鎖定(如依零碎資訊推斷人員位置)與傳統武器開發(如設計打擊移動目標的無人機)方面的能力。評測顯示模型在模擬情報與武器開發任務上持續進步。

過去一年,我們的威脅情報團隊調查阻斷多個利用 Claude 開發武器軟體、或支援武器計畫所需情報蒐集與採購的威脅行為者。本報告分享其中六起案例:三起在中國、兩起在俄羅斯、一起在葉門。

過去這類活動多由政府、聯合國專家小組與外部調查人員從回收硬體與公開資料拼湊追查。但身為前沿模型供應商,只要偵測到違反使用政策與服務條款的行為,我們就能自行發現這類活動——封禁違規帳號、把調查發現納入防護機制,並向公私部門合作夥伴提供資訊以降低威脅。

本節六案例分兩部分。第一部分四起案例,行為者用 Claude 開發武器本身軟體:含實地測試的導引火箭計畫;攔截魚雷系統的設計提案;經模擬測試並將程式碼載入實體開發板的無人機蜂群軟體;用於電子戰與壓制防空系統的鎖定軟體。第二部分兩起案例,行為者用 Claude 進行採購與情報蒐集:一名為俄羅斯國防客戶採購軍民兩用物資,另一名蒐集定向能武器及其供應商的公開資訊。

我們已把調查發現納入防護機制改善工作,最近推出新分類器以更有效偵測、攔截與高當量爆裂物及武器開發相關的流量。

我們希望本報告有助於資安社群、各國政府與公民社會共同守護系統,防範 AI 工具遭用於傳統武器開發。

### 第一部分:武器研發與設計

本節討論我們阻斷的四項傳統武器相關行動。所謂「阻斷」,是指封禁所有能與該行為者連結的帳號,使整個行動停擺;若行為者同時在其他平台活動,我們會與業界夥伴分享調查發現以便對方也能阻斷,並視情況與其他公私部門合作夥伴分享威脅情報。

這些案例中,行為者皆利用 Claude 針對自己原本已具備專業能力、也能取得的武器硬體與韌體進行建構精進,並把工作拆分到許多對話階段以掩蓋計畫全貌,同時使用其他手法規避我們的防護機制與存取控管。
